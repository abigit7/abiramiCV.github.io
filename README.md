# 🌐 My First Web Development Project

## 🌟 Overview
This is my first-ever project in **web development**, built using only **HTML & CSS** when I was in **11th grade**! 🎉 It’s a simple yet meaningful project that marks the beginning of my journey in tech. 💻🚀

## 🔥 Features
- 🏗 Basic webpage layout
- 🎨 Styled using only CSS
- 📱 Responsive design (basic)
- 🌟 Simple yet effective UI

## 🛠 Installation
1. Clone the repository: 📥
   ```sh
   git clone https://github.com/abigit7/abiramiCV.github.io.git
   ```
2. Navigate to the project folder: 📂
   ```sh
   cd my-first-web-project
   ```
3. Open the `index.html` file in your browser 🌍

- Modify the code to experiment with HTML & CSS.
